# 当当老师 · 立体切割实验室

独立地址：https://dangdanglaoshi.cn/solid-slice-lab/

小屋右侧“游戏”列表可以直接进入；页头“返回小屋”回到首页。

小屋二楼地毯前方放置独立的“几何切割台”，台上有蓝橙色分离方块、黄色切面及小圆柱和圆锥。点击实物或提示按钮，先播放切割分离动画，再进入实验室；第一人称可以靠近后按 E。完整房屋模式隐藏穿墙提示，返回/后退时复位动画；碰撞体只作用于二楼。手机可直接点按实物。

保留原版正方体、3—6 棱柱和棱锥、角度输入、切面平移、切割分离与视角控制。点击 2 个顶点锁定切面轴线，拖动角度时保持经过这 2 点；点击第 3 个非共线顶点确定切面。切换形状与清除选择可以重新操作。

新增长方体、圆柱与圆锥。左侧“想切成什么截面？”提供已计算并验证的自动定位示例，选择后同步调整倾角、方向及偏移，并清除已有顶点锁定。定位后可自由调整，也能点击“重新定位所选截面”恢复。

- 圆柱：圆、完整椭圆、长方形。
- 圆锥：圆、完整椭圆、通过顶点的三角形。
- 多面体：按当前立体及底面边数，提供实际验证过的三角形、正方形、长方形、菱形、平行四边形、梯形及多边形等示例。
- 圆柱/圆锥不能切成的直边多边形显示为不可选，并说明原因；多面体尚未收录的姿态只标“暂无定位示例”，不据此断言数学上不可能。
- 截面正视图直接使用同一组截面坐标，帮助区分真实的圆/椭圆与透视效果。圆柱和圆锥使用解析曲面求交，再细分描绘边界；倾斜截面若被底面截断，明确标注“含曲线的截面”，不会伪称梯形。
- 分离后，两侧黄色截面随各自实体移动。三点定面保留完整计算精度，仅在角度输入框中简化显示。

本版本使用当当老师 Logo 和动漫头像，移除旧版照片及其他品牌背景。所有图片和 Three.js 都内嵌到构建结果，不依赖外部 CDN。

## 启动与发布

Node.js 22.13+：

```sh
npm install
npm run dev
npm run build
npm test
npm run test:math
node cabin.test.cjs
```

`npm run build` 输出仓库 `site/solid-slice-lab/index.html`，也可复制这个 HTML 后直接双击打开。`npm test` 使用同仓库 geometry-board 已安装的 Playwright，对实际构建运行浏览器检查。

`index.html`：页面与样式；`main.ts`：Three.js 场景、自动定位和顶点锁定；`sections.ts`：几何模型、截面分类、圆柱/圆锥解析求交及定位姿态目录；`assets/`：当当老师品牌图片；`sections.test.mjs`：67 个定位姿态及 160 个随机倾斜曲面截面检查；`browser.test.cjs`：全部可用目标的实际操作、不可行目标拒绝、手机、离线及入口检查。`npm run build` 包含 TypeScript 严格类型检查。
