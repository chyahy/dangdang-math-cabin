# 当当老师 · 魔方旋转室

真实三阶魔方与同步贴片轨迹图。支持六面旋转、正反方向、半圈、自由观察、触控捏合缩放、逐步演示、公式输入、随机打乱、撤销和重做。

## 构建与测试

从仓库目录运行：

```sh
node apps/cube-rotation/model.test.cjs
node apps/cube-rotation/build.mjs
```

输出为 `site/cube-rotation/index.html` 及工作区根目录的 `当当老师-魔方旋转室（离线版）.html`。两份均为单文件，无外部字体、网络资源或服务器依赖，保留内嵌 Three.js MIT 许可证。用现代浏览器打开即可。

源代码 `index.html` 中的库链接仅用于构建占位，请打开生成的 HTML。

## 模型与坐标

X 向右，Y 向上，Z 向前。每个小块用整数位置存储，54 张贴片拥有独立 ID 与法向量。动画在临时父对象中进行，完成后用精确的整数旋转矩阵更新状态并重建视图，不累计浮点误差。顺时针均指面对对应面的观察方向。

轨迹图采用独立的固定轴测投影，投影数据是贴片的真实三维中心，运动路径使用与三维魔方相同的旋转轴、方向与角度。浅色环作坐标参考，亮点与彩色弧为当前层的运动。

不包含自动求解、魔方输入识别、账号和云保存。
