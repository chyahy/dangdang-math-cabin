# 数轴实验室 · 当当老师

独立网址：<https://dangdanglaoshi.cn/number-line-lab/>。同时接入游戏广场、小屋侧栏和屋外右侧的数轴教具。保留原来的“有理数与数轴”游戏。

## 启动与构建

需要 Node.js 22.12+。

```powershell
cd apps/number-line-lab
npm install
npm run dev
npm test
npm run build
```

`npm run build` 输出 `dist/`，`npm run preview` 可预览。部署到主站时，从本目录运行 `npm run build:site`，然后在仓库根目录运行 `node apps/portal/build.mjs`，恢复广场播放器与独立返回链接。

## 如何操作

- **自由数轴**：点击“添加点”后点画布。拖圆点移动；点下面的坐标框可输入 `-3`、`0.5`、`1/3`。重命名、删除、高亮均在点卡片上。最多24个点。
- **视图**：拖空白平移，滚轮以鼠标为中心缩放。手机双指捏合缩放，双指同时移动可平移。“初始视图”回到−10到10；点超出视野时可显示全部点。坐标不会随视图改变。
- **吸附**：整数、分数、自由移动。分数分母有2、3、4、5、10；放大时显示相应细刻度。精确输入不受拖动吸附限制。聚焦点手柄后左右方向键也能调整。
- **相反数**：拖任意一边，两点同步关于0对称；辅助线可开关，提供5个探索问题与解释。
- **绝对值**：数字/距离/方程三种视图。方程 `|x|=a` 可精确输入或滑动a，自动计算0、1、2个解；拖动解的手柄也能改变非负参数。
- **两点距离**：两个点独立拖动，重合时手柄上下错开。显示距离、坐标差或完整公式，支持自定非负目标距离。
- **加减法**：输入两个有理数及运算符，点播放；可暂停、重播、单步、跳到结果及调整速度。减法显示“加上相反数”。
- **探索挑战**：15个操作任务，按真实数值判定（包括全部解、任意距离、分数），提供两级提示、解释、再试一次和完成记录。
- **课堂教学**：放大关键文本；隐藏坐标标签/结论、投影高对比、典型例题、全屏、恢复视图与重置。隐藏坐标标签仍保留教师的精确输入框。
- **撤销/重做**：按钮或 Ctrl/Cmd+Z、Ctrl/Cmd+Shift+Z、Ctrl+Y。一次拖动作为一次历史操作，最近80次；历史不跨刷新保存。
- 所有实验的数值与视图分别保留，自动保存在当前浏览器本机。无账户、无后台、无付费API。

## 计算与范围

有理数使用约分后的BigInt分子/分母进行加减、相反数、绝对值和距离计算。只有显示和鼠标映射转换成浮点坐标。输入支持±1000000以内的数，小数最多6位、分母不超过1000000000；自由拖动精度为百万分之一，实际输入错误会明确提示。表达式用本地打包的KaTeX显示，无CDN请求。

## 验证与边界

自动化测试覆盖0、负数、交换点、重合、负参数无解、方程全部解、各符号组合、精确分数、缩放锚点、平移不改数学值，以及15个任务的正确/错误答案。浏览器验证记录见 `QA.md`。

不包含账户、云同步或自动生成证明；本地文件需通过开发服务器/静态HTTP服务器打开，并非双击即可运行的单HTML离线版。
