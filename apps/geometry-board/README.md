# 交互几何画板 MVP · 当当老师

React + TypeScript + Vite + Tailwind CSS + SVG。不是静态图片或原型；自由绘图和例5使用完全相同的点、图形引用、指针控制和旋转函数。

## 小屋入口

小屋二楼地毯旁有独立支架的“几何旋转画板”，不占书桌、不依附外墙；点击教具或浮动提示会播放三角形旋转与画板展开动画，然后进入 `/geometry-board/`。右侧游戏列表中的“交互几何画板”可以直接进入。第一人称准星选中教具后可点击或按E交互。浏览器返回会重置过场；画板顶部“回到小屋”返回小屋首页。减少动画偏好下缩短过场。

## 启动

在本目录打开终端：

```powershell
npm ci
npm run dev
```

按终端显示的本地地址打开（默认 `http://127.0.0.1:5173/`）。需要 Node.js 22.12+，本次使用 Node.js 24。

```powershell
npm test
npm run build
npm run test:ui -- --workers=2
```

首次运行浏览器测试如缺少 Chromium，运行 `npx playwright install chromium`。生产构建输出 `../../site/geometry-board/`，可与现有小屋一起部署，独立地址为 `/geometry-board/`。开发地址使用 HTTP，不应双击生产 HTML 使用 `file://` 打开模块脚本。

## 如何使用

- 点：点击空白处自动按 A、B、C…命名；靠近已有点直接复用。超过 Z 后使用 AA、AB…。
- 线段：依次点两个顶点。既可以点已有点，也可以点空白处创建点。
- 三角形：依次点三个不同且不共线的点，自动完成并选中。
- 多边形：依次点多个顶点，最后点起点闭合；也可以按 Enter 或右侧“闭合多边形”。
- 选择：点击多边形内部或线段；拖动顶点时关联线段和多边形实时更新。右侧对象列表也可选图形。
- 选顶点：例如按顺序点 A、B、D，组成临时 △ABD，不会重新绘制四边形或插入额外对象。点击“完成选择并旋转”后指定中心。未选图形就点“旋转”也会进入此流程。
- 旋转：选图形 → 旋转工具 → 点击中心（已有点或画布空白处）→ 拖绿色手柄/输入角度/滑块/快捷角度 → 确认或取消。
- 数学坐标 Y 向上，正角为逆时针，负角为顺时针。方向按钮控制输入框、滑块与快捷角度。鼠标手柄也可自由顺/逆时针拖动；按 Shift 吸附到15°。
- 默认复制旋转：所有副本顶点都有独立ID，包括与中心重合的顶点。副本使用 A′、B′…，如名称已用则继续增加撇号。
- 取消旋转不产生点或对象。每次角度变化都从本次初始坐标使用标准旋转矩阵计算，不在上一帧上累加坐标。
- 原图为蓝色，旋转预览为绿色，中心和角度圆弧为橙色。预览角度为0或360°时副本与原图重合属于正常情况。
- 如果关闭“复制后旋转”，确认时会移动原顶点，关联图形随之变化；界面明确提示此影响。预览期间仍不修改原图。
- 滚轮缩放以鼠标位置为锚点；选择模式拖空白处、平移工具、按住空格或鼠标中/右键拖动均可平移。触屏支持双指同时平移和缩放。
- 右下“完整显示”将原图和旋转预览一起纳入画面。角度输入或快捷操作使副本超出视野时自动缩小适配；鼠标旋转只在松手后适配，不在拖动过程中改变相机造成角度漂移。确认后适配所有对象。
- 删除对象保留其顶点；删除顶点会同时删除关联对象，避免悬空引用。可撤销恢复。临时顶点组合没有对应实体，“取消顶点组合”或Delete只取消选择，不破坏原图。
- 本地保存只保存已确认的几何数据和视图，不把旋转预览当成已确认对象。刷新后恢复最近一次手动保存的内容。
- JSON可跨设备保存/加载；导入有版本、数量、坐标、引用和颜色检查，失败不破坏画板。
- PNG导出当前可见区域，包含旋转预览与角度，不包含拖动手柄和按钮。先点“完整显示”可以导出完整图形。
- 撤销/重做记录几何事务：一次拖点只记一步；不把每一帧或单纯视图平移缩放加入撤销栈。最多保留100步，历史只在本次会话有效。
- 快捷键：V选择、P点、L线段、T三角形、G多边形、J选顶点、R旋转、H平移、Delete删除；Ctrl/Cmd+Z撤销、Ctrl/Cmd+Shift+Z或Ctrl+Y重做、Ctrl/Cmd+S本地保存、Escape取消。

## 例5与原题核对

用户提供的照片与文字一致：∠ABC=30°，∠ADC=60°，AD=CD，求证 BD²+AB²=BC²。

这些已知条件**不能保证给定结论**。为避免用错误图形模拟证明，本预设使用以下真实坐标（布局与照片方向接近）：

```text
D = (0, 0)
A = (2√3, 2)
C = (2√3, -2)
B = (6√3, 2)
```

它是凸四边形，严格满足 AD=CD=4、∠ABC=30°、∠ADC=60°；但 BD²=112、AB²=48、BC²=64，所以160≠64。这提供了反例，说明应核对原书是否有勘误或遗漏条件。界面显示原题和实测值，并保留“题干待核对”提示，不声称已经证明。

操作：“加载例5” → “选择△ABD” → “以D为旋转中心” → “旋转60°（顺时针）”。A旋转后与C重合，预览标注“A′ = C”；确认后副本拥有独立顶点。拖动原图顶点后，已知条件状态和实测角度长度实时更新，不再强行重合。可以继续画辅助线，例如连接 B 与 B′。

## 文件划分

| 文件 | 职责 |
| --- | --- |
| `src/model.ts` | 点ID、图形引用、选择、文件数据类型与命名 |
| `src/geometry.ts` | 旋转矩阵、坐标换算、命中、缩放锚点、面积与角度 |
| `src/Board.tsx` | SVG网格、几何对象、旋转前后、中心、角度圆弧与手柄 |
| `src/useBoardInteraction.ts` | 指针捕获、点拖动、点击绘图、手柄旋转、平移、双指与滚轮 |
| `src/App.tsx` | 工具状态机、构图、顶点组合、旋转面板和文件交互 |
| `src/preset.ts` | 例5真实坐标及已知条件实测 |
| `src/useHistory.ts` | 独立事务快照、撤销重做、拖动取消 |
| `src/persistence.ts` | 本地存储、JSON校验及PNG导出 |
| `src/geometry.test.ts` | 数学计算、随机旋转、坐标转换、引用和文件校验测试 |
| `e2e/board.spec.ts` | 三个核心流程及鼠标、触屏、保存/导出实际浏览器测试 |

## 验证范围与边界

- 32项数学测试覆盖顺逆时针、连续改角度不累加、1,000组随机旋转边长不变和缩放坐标往返、例5已知条件、独立副本、删除引用清理和无效JSON。
- 15项浏览器测试覆盖自由绘图→旋转、已有四边形选择ABD→鼠标手柄旋转、例5旋转→继续作辅助线，以及拖点、撤销重做、点复用、PNG/JSON、本地保存和触屏响应式；还检查画布外松手、失焦回滚、重复副本撇号、原图旋转及任意空白位置作中心。4项小屋集成测试检查侧栏入口、真实三维物品射线点击、第一人称E键、返回复位、移动端和减少动画模式。
- 鼠标与触屏测试使用本地Chromium及移动触屏仿真；没有逐台实测真实iPhone Safari或安卓厂商浏览器。
- 角度范围为 -360° 至 360°，任意中心，支持小数角度；本版不提供多圈累计旋转输入。
- 保存的是自由坐标，**不做几何约束求解**：拖点不会自动保持30°、60°或等边关系，已知条件不成立时会如实提示。
- 不含自动证明、AI识题、3D、账号、云端数据库，符合本次排除范围。
- 本版支持点、线段、三角形、多边形；圆、射线、垂直/平行约束等未列入此次MVP。
- 本地记录不跨设备同步；JSON可手动转移。清理浏览器站点数据会清除本地保存。
