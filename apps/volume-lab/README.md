# 3D 容积实验室 · 当当老师

面向小学中高年级的纯前端交互实验。透明水箱、逐层方块装箱、量杯倒水共用精确的单位计算，不使用后端或付费 API。模型、刻度与标签均在本地生成，不下载模型、图片、字体或环境贴图。

## 启动

需要 Node.js 22.12 或更高版本，推荐 Node.js 24。

```sh
npm install
npm run dev
```

打开终端给出的本地地址。生产构建和预览：

```sh
npm run build
npm run preview
```

标准构建输出在项目内的 `dist/`，可托管到任意静态站点平台。Vite 使用相对资源路径，支持子目录部署。

在「当当老师的小屋」仓库中，`npm run build:site` 直接生成 `site/volume-lab/`。该命令仅供仓库集成使用，单独下载项目请使用普通 `npm run build`。

### 单文件离线使用

```sh
npm run build:offline
```

生成 `dist-offline/index.html`，可直接双击用 Edge 或 Chrome 打开。Three.js、React 和界面样式全部内嵌，无需启动服务器，也无需联网。源码包中附有已经生成的离线文件。

## 使用方式

### 透明水箱

水箱**内部**尺寸 10 cm × 10 cm × 10 cm。拖动滑块或输入当前水量，水位立即同步；快捷水量按钮平滑切换。设置「单次注入 / 排出」后点击相应按钮。动画可以暂停、继续或直接到位。

- 水位高度始终为 `mL / 100`，没有人为设置最低显示水深。
- 1 mL 的主水箱水深是 0.01 cm。少量水时出现「局部放大」窗口：它只改变观察相机的放大倍数，主水箱尺寸与水深保持原比例。
- 另有边长 1 cm 的小水盒作为**等体积对照模型**，不是水箱内水量的一部分。
- 侧面 100—1000 mL 刻度、三条 10 cm 尺寸线都随 3D 模型显示。

### 立方体装箱

每块实际几何边长为 1 cm，没有把方块缩小来制造缝隙。用 `InstancedMesh` 绘制 1000 个位置，再用单个线段缓冲区画出各块边界。

- 滑块和数字输入支持 0—1000 个，0 为空箱。
- 「开始装箱」逐层加入方块，可暂停、继续、1×/2×/4× 加速与跳过。
- 每层 10×10=100 个，共 10 层。
- 「只看 1 个」聚焦独立的 1 cm³ 对照方块。
- 「剖层观察」临时隐藏上方的方块，数量、总容积及换算结果不变，页面明确标注可见层数。

### 量杯倒水

初始量杯 1000 mL、水箱为空。选择本次倒入 100、250、500 或 1000 mL；余量不足时倒入全部余量。动画包含准备、倾倒和归位。

- `cup + tank = 1000 mL` 在每一个状态更新中精确成立。
- 水流和水滴只是视觉示意，不另外加入或扣除水量。
- 量杯的水面按重力保持水平，不随杯体作为刚体一起歪斜。
- 量杯内半径为 5 cm，高为 `1000 / (π×5²)` cm，实际圆柱容积为 1000 cm³。
- 倾斜角度由当前剩余水量计算；用圆截面的稳定高斯积分和二分法确定液面，裁剪出杯内的水体，避免水穿出杯壁。
- 修改换算面板时，可直接重新分配杯与水箱中的水，但两者之和仍为 1000 mL。

### 换算与教学

四个输入框均可修改：mL、L、cm³、dm³。按 Enter 或移开焦点提交，输入期间先暂停实验，避免读数在编辑时变化。

- `1 mL = 1 cm³`，`1 L = 1 dm³`，两组之间相差 1000 倍。
- 非负十进制数，支持 `.5` 这样的简写；mL/cm³ 最多 6 位有效小数，L/dm³ 最多 9 位有效小数。多余的末尾零可以输入。
- 换算上限为 1 万亿 mL。超过水箱容量时仍展示换算，明确提示超容量，并保留模型原先的实际装入量。
- 装箱中的小数体积可以换算，但不会生成半个小方块，界面会说明实际数量未改变。
- 三张知识卡点击后调用对应模型并聚焦；四道挑战题提供反馈与「用实验验证」。

## 操作与状态

- 鼠标拖动旋转，滚轮缩放；手机单指旋转，双指缩放和平移。
- 「恢复正面视角」重设相机。手动操作相机会中止自动聚焦。
- 「全屏授课」显示主要实验，浏览器不支持时可横屏使用。
- 顶部「重置本实验」只重置当前模式。切换模式保留各自数据并暂停离开的动画。
- 页面隐藏时暂停动画。系统开启「减少动态效果」时，注水和装箱等直接到位；该偏好改变时会实时生效。

## 数学与精度约定

`1 个内部量 = 0.000001 mL`，使用 `BigInt` 存储与换算。所有显示通过整数除法格式化，不出现二进制浮点尾数。3D 几何计算时才转为有限范围的厘米数值。

水箱中的水体几何尺寸为 `10 × (mL/100) × 10`。微小表面波动采用两向正弦、平均位移为零；波幅随水深减小，满箱时为零。它不改变实际平均体积。

方块编号 0—999 的中心坐标：

```text
x = (index % 10) - 4.5
y = floor(index / 100) + 0.5
z = (floor(index / 10) % 10) - 4.5
```

所有实际几何与状态验算均使用这些统一的尺寸。

## 测试

```sh
npm test
npx playwright install chromium
npm run test:ui
npm run test:offline
```

单元测试涵盖四单位精确换算、2000 次单位往返、水位、1000 个独立方块位置、量杯水平截面与裁剪、每帧倒水守恒、重复倒水、暂停跳过、模式隔离和超容量行为。

浏览器测试使用真实 WebGL，验证三种模式、少量水局部放大、输入、装箱剖层、动画暂停/继续/跳过、知识卡、四道挑战及手机横竖屏。测试截图在 `test-results/`。

本版不包含账号、云端存档或跨设备进度同步；刷新页面回到初始实验状态。
