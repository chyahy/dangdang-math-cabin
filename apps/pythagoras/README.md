# 勾股定理 · 看见证明

当当老师现有网站内的教师演示课件，正式路径 `/pythagoras/`。React、TypeScript、Vite、原生 SVG、KaTeX；无登录、积分、题目或游戏机制。沿用网站既有 logo。

包含直观引入、四三角形拼接（计算法与重排法）、加菲尔德梯形、等积变换、相似三角形（投影与视频面积法），以及六项自由实验。参考视频分镜见 [video-analysis.md](video-analysis.md)。

## 使用

- 点击“播放此步”或“下一步”，只播放到下一个构造点并自动停止。中途可暂停并从原位置继续。
- 左右方向键：退/进一步；空格：播放/暂停；R：重播当前证明；F：全屏；Esc：退出教师演示布局。
- 每个证明保存独立的当前进度、目标进度。切换时暂停，回来后可继续。课堂进度仅保留在当前页面会话，刷新从头开始。
- 教师侧栏提供提示、步骤选择、a/b 滑块、3-4-5 和 5-12-13 预设、四种展示层次与独立可见性开关。“完整推导”只显示**当前步骤已到达**的公式。
- 直观引入可拖动彩色端点；等底等高可拖动顶部顶点。触控、鼠标均可。所有滑块也可用键盘调整。
- 四三角形有来回切换与左右对照；梯形可分离/恢复、点击高亮区域；相似比例式可点击/悬停对照对应边。
- 教师演示模式隐藏侧栏、导航，放大图形和公式。画面左侧 20% 返回一步，右侧 20% 进入下一步。
- 自由实验最后一项解除直角约束，角度 25°–155°，严格按余弦定理展示面积差。a、b 为两条边，不再称“直角边”。

## 数学与动画

`geometry.mjs` 提供顶点、边长、外接正方形、多边形面积、旋转/平移矩阵、垂足、相似比、直角判断、边界、等积剪切与时间推进函数。图形始终用实际数学单位计算，最后以统一比例投影到 SVG。三角形的边长改变会重新计算所有构造。

四三角形的每一块只使用欧氏旋转、平移。重排路径分六段：第一块移到左侧、第三块移到右侧、第四块移动到新位置、第一块在外侧下移并放回、第三块从右侧放回。每段允许停在任意位置。测试逐段检查三角形之间不相交。

面积证明的两个剪切均保持固定底和相应的高，**允许形状改变，面积不变**。它们不属于刚体运动。为了说明不是借待证结论拼图，可直接以斜边坐标建立理由：B=(0,0)、C=(c,0)、A=(m,−h)，n=c−m。直角条件 AB·AC=0 给出 h²=mn，不使用勾股结论。蓝色方形在 B 的两条边向量为 u=(m,−h)、v=(−h,−m)。第一次 v→v+(h/m)u，行列式不变，第二向量成为 (0,−c)，因为 m+h²/m=m+n=c。第二次保持此竖直底，把 u 的竖直分量连续移到零；水平间距 m 不变。得到 m×c 矩形，再纯平移到 c 方形内。绿色部分对称得到 n×c。m+n=c，两个矩形恰好铺满。`m=a²/c` 在程序中只是高线投影坐标的数值生成方式；讲解不把该式作为未证明的前提。

相似证明中 A 为直角、D 为高线垂足，AB=a、AC=b、BC=c、BD=m、DC=n。△DBA∼△ABC 给出 m/a=a/c，△DAC∼△ABC 给出 n/b=b/c。统一斜边选项仅改变比较副本的相似比例，不改变原图，不将缩放后面积相加。镜像方向不影响相似判定。

直观填充按 a²/c² 和 b²/c² 分割 c 正方形，不声称流体动画是严格证明。非直角实验禁用此填充，差值按真实距离与 2ab cos θ 计算。浮点数仅用于几何长度与显示；这里没有连续分数运算。

每个步骤有 stepId、标题、提示、公式、突出区域和时长；连续数学状态由进度唯一推导，不依赖前一次 DOM 动画结束事件。requestAnimationFrame 每次只推进到本次目标，暂停时不再累积时间。前后台切换暂停，速度提供 0.5×/1×/1.5×/2×。

## 开发与验证

```powershell
cd D:/dangdanglaoshi/apps/pythagoras
npm ci
npm run dev
npm test
npm run build
node ../../apps/portal/build.mjs
node tests/browser-qa.mjs
node build-offline.mjs
```

浏览器 QA 使用本机 Edge，默认连接仓库静态服务器 `http://127.0.0.1:4186/pythagoras/`。先在根目录运行 `node apps/solid-geometry/serve.cjs`。可通过 `PYTHAGORAS_QA_URL` 指定其他已授权测试地址。输出截图与检查记录均写入本机已排除的 `outputs/pythagoras/`。

构建发布目录是 `site/pythagoras/`，封面由模块构建复制到 `site/portal-assets/`；之后必须执行门户构建安装返回脚本。离线 HTML 将 JS、CSS、字体和 logo 内嵌，断网可打开；返回网站的链接需要联网。
