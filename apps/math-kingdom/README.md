# 数学王国：运算攻城战

当当老师的双人数学策略课堂游戏。基于已有单词王国的触控、Phaser战斗和本地存储架构建立独立项目；英语版的题库、素材、设置与代码不被覆盖。

## 启动

需要Node.js 22.12或更新版本。

```powershell
npm install
npm run dev
```

开发服务器默认5173；也可 `npm run dev -- --port 4198`。

```powershell
npm test
npm run build
node scripts/serve.cjs --open
```

生产预览为 `http://127.0.0.1:8918/`。停止服务器按Ctrl+C。运行时无需后端、CDN、外部字体或付费API。

## 完整玩法

1. 教师选择年级、知识点、难度、时长、题库来源和题型权重，默认四年级、240秒、策略模式。
2. 左右两队各有数字键盘。点击数字输入，退一位/清空/确认；初一启用±，五年级及初一启用小数点和分数线。分数以a/b输入，`0.75`、`3/4`、`6/8`判作相同数。
3. 简单/标准/挑战题分别奖励15/20/30金币；每3连击额外5。巧算题选择一个实际等价的变形式额外5，不通过答题速度推测方法；多个数学上正确的选项都接受。
4. 小兵20、弓箭手35、战锤重装骑士100金币。初始0金币和150HP，学生决定先出便宜兵还是储蓄精锐。答对不会直接赠送士兵。
5. 自动模式按教师配置的3个兵种顺序循环，存够目标价格再购买，不偷换便宜兵；自动模式关闭手动购买。每队最多30个存活单位，达到上限拒绝购买且不扣钱。
6. 兵种自动找敌人、移动、攻击和攻城。小兵1点护甲，骑士5点护甲；弓箭手发射独立像素箭矢，飞到目标才扣血。已死亡的目标从战斗中移除。
7. 城堡归0立即停止业务状态；城堡局部坍塌播放0.85秒后显示结算。时间到依次比较城堡HP、累计获得金币、正确率，再相同平局。剩余未花金币不是累计金币。
8. 暂停冻结全部业务状态；页面失焦或隐藏会自动暂停，必须点击继续。全屏、重开、退出、音量调节、历史战绩和错题CSV均可用。

双方城堡配有自动箭塔：优先瞄准420世界单位射程内最近的存活敌兵，每1.5秒射出一支箭，基础伤害12点，按兵种护甲减伤，实际命中才扣血。防守不花金币、不增加答题金币；目标死亡后在途箭失效，不转移伤害。箭塔弩机有发射反馈，箭矢从塔楼飞向敌兵；倒计时、暂停、比赛结束或城堡摧毁后停止射击。红蓝参数一致，新局重置冷却。

正确率分母为答对+答错+跳过。最近50场战绩来自真实完成对局，保存在当前浏览器。没有云账户或跨设备同步。

## 数学与题库

内置260题，按三个年级组织，覆盖整数加减乘除、运算顺序、混合运算、交换律/结合律/分配律、简便运算、小数、分数、数量关系、正负数、有理数、绝对值、代数式求值与一次方程。属于主题示例，不宣称与某版本教材逐课匹配。

网站另随附《四年级-乘法巧算口算进阶-40题-数值计算.csv》的40道题，归入自定义题目，四年级、标准难度、数值计算。每个浏览器首次加载本题包时自动加入，因此新电脑也可使用。已有相同年级、算式、题型和字母赋值的题目会保留原记录，避免重复；安装后在本机修改或删除会保留。去设置选择“自定义题目”即可只练自定义题。此固定题包随网站发布，教师之后自行新增的题目与设置仍只保存在本机浏览器，并非云同步。

题型为 `calculate`、`missing`、`method`、`fraction`。题型权重控制有限题库的抽取顺序，0关闭该类型；每轮无重复，有限题库每轮最终构成受现有题量约束，不把顺序权重宣称为无限题目的精确比例。用完后可选择明确标记轮次后循环，或本队停止出题。

所有参考答案由安全表达式解析器和BigInt有理数精确计算；不使用eval或浮点直接相等。支持四则、括号、平方、绝对值、字母代入，以及唯一解的一次方程；拒绝除0、未知表达式、过长输入、非唯一填空答案。四/五年级检查中间结果，防止隐藏负数；四年级拒绝非整数中间结果。难度由经过校验的题型/运算步骤规则或教师显式标注，不依据数值大小自动打分。

后台可切换内置题目与自定义题目，两类分别显示，搜索、年级筛选和分页只针对当前类别。新增或导入自定义题后自动切到自定义列表。支持添加、修改、删除、下载模板、Excel/CSV导入、预览错误和导出完整题库。表头：

```text
expression,answer,grade,topic,difficulty,type,options,explanation,context,environment
```

- `expression`：`48×25`、`□×25=400`、`1/2+1/4`、`-3-(-5)`。
- `answer`：整数、小数或分数；系统重新计算并核对。
- `grade`：四年级/五年级/初一；`difficulty`：1/2/3。
- `options`：巧算的2～4个算式，用`|`分隔；至少1个等价、1个不等价。不能用`|x|`作选项分隔中的绝对值，改用`abs(x)`。
- `explanation`：教师解题提示；`context`：可选补充题意。
- `environment`：字母赋值JSON，例如 `{"a":"-4","b":"2"}`。这些值属于题目，导出再导入不会丢失。
- 单次最多5MB、2000题，只读取第一张工作表；非法、重复和参考答案错误的行不会保存。CSV按原始文本读入，防止分数被自动转成日期。

## 像素美术

参考用户提供的三职业设定，采用大头短肢、粗暗色像素边、有限色阶和统一脚底锚点。六套红蓝变体拥有独立轮廓：短剑小盾兵、绿色兜帽弓手+阵营披风、战锤+金边大盾骑士。每角色26帧，64×44透明帧；城堡每套20帧，80×96。详细素材清单、帧率、锚点及可重建脚本见 `public/math-pixel/ART_MANIFEST.md`。

战场原生640×90，使用1/3相机观察1920×450数学世界的前景区域；宽度为1920/1280时分别约3/2倍显示，不纵向挤压角色。最近邻采样、整数像素绘制、像素箭矢、共享图集缓存与有限对象池。背景为独立副本，白云/旗帜动态，未声称提供完全独立的五层背景视差素材。生成封面及背景来源与提示词见 `ART_ASSETS.md`。

界面采用木质方键、像素金币、兵种头像、城堡血条和像素奖杯。数学符号与中文使用清晰字体，不为像素效果牺牲课堂可读性。

## 项目结构

```text
src/math/rational.ts       精确有理数、安全解析器、年级检查、一次方程
src/questions/             内置题、筛选、洗牌、方法等价验证、题库校验
src/engine/                唯一权威Match、金币商店、自动购买、弹道、胜负
src/scenes/                Phaser渲染、原创像素图集、Web Audio
src/components/            独立Pointer按钮、两队键盘与商店、教师后台
src/storage/               独立IndexedDB、Excel/CSV读取、错题导出
src/store.ts               React/Zustand连接与完成对局保存
public/math-pixel/         真实PNG图集、头像、箭矢、城堡、帧定义和资产说明
scripts/                   本地服务器、离线/源码ZIP打包
```

## 离线版与发布

`npm run build` 后执行 `npm run package`，在 `release/` 生成 `math-kingdom-offline.zip`、`math-kingdom-source.zip`。离线包解压后双击 `start.cmd`；预先安装一次Node即可，游玩时无需安装依赖或联网。ES模块不能直接双击dist/index.html运行。返回游戏广场按钮会打开在线网站。

`npm run build:site` 输出到小屋仓库 `site/math-kingdom/`，再于仓库根运行 `node apps/portal/build.mjs` 更新广场、播放器、版本和返回入口。独立链接 `/math-kingdom/`；小屋侧栏与游戏广场都有入口。

## 验证限制

自动测试和浏览器验收见 `QA.md`。有双队PointerID独立处理及轮流降级，但未连接真实65/75寸触控设备。浏览器鼠标测试不能冒充硬件同时双触测试。60FPS是优化目标，不能保证每台教学屏达到；教室使用前仍需在实际设备检查驱动、声音、性能和误触。
