# 数学王国像素实施规范

数学版独立于英语版，使用React + TypeScript + Vite + Phaser + Zustand。引擎与题目、数学与屏幕坐标分离，所有金币、生命、答题、胜负只来自同一个Match；React不自行计算另一套成绩。

参考图的核心是大头短肢、暗色阶梯轮廓、头盔硬亮面、简化面部与夸张武器。角色64×44，脚底(24,41)，站立头部约占全身1/3；阵营披风、头饰、盾牌均成片换色，绿兜帽仍保留职业特征。重骑士体量更大、盾更宽，战锤以不同朝向的矩形像素面和锤击尘土表现重量。

统一色板：描边深墨`#19283b`，羊皮纸`#f2dfb4`，金币金`#e2a73d`，赤焰`#b84847`，星蓝`#397db2`，树林绿`#52774b`。标题使用粗中文字体，算式与数字使用Consolas/中文回退；不要把题目转为低清位图。

布局：顶部生命/时间 → 横向像素战场 → 左右对称的题目、独立数字键盘、兵营 → 教师工具。关键辨识点是“金币袋正下方的三职业兵营”：孩子能直接看出计算的收益、买得起的单位与自己的队伍。

控件触摸尺寸以真实CSS像素计算，不能按低分辨率Canvas做事件坐标映射。每个按钮维护独立pointerId，pointerup触发一次，取消/移出不触发，真实硬件不支持多点时教师可选轮流模式。

美术复核：数学版不导入英语版运行时素材路径；独立PNG图集、头像、箭矢与城堡均可单独使用并可离线重建。背景为已有原创像素景观的独立副本，封面以数学木牌替换英语字母。代码生成像素资产，未用整张人物设定图充当战场。
