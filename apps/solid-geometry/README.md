# 当当老师 · 立体图形观察站

在用户提供的 `solid-geometry.html` 基础上扩展，原文件保持原样。

## 新增功能

- 7 种多面体沿公共棱连续展开与收回，可用滑块停在中间状态。
- 正方体 11 种不同展开图，附可点击缩略图；镜像和旋转重复形状不重复列出。
- 圆柱：长为 2πr、宽为 h 的长方形及 2 个圆形底面。
- 圆锥：母线为半径的扇形及 1 个圆形底面，扇形角为 360°×r/l。
- 球的无变形完整展开不可能，页面明确说明，保留其立体观察功能。
- 尺寸滑块和数字输入同步，体积、表面积与展开图实时更新。
- 当前画面导出 PNG，完整显示、全屏、手机双指缩放和平移。
- 小屋门边独立几何展台、展开入场动画、侧边快捷列表、第一人称 E 交互和返回小屋。
- 小屋射线交互按实际距离选择物品，避免后方门窗抢占眼前展台的操作。

## 构建、预览和测试

在仓库目录运行：

```sh
node apps/solid-geometry/build.mjs
node apps/solid-geometry/serve.cjs
```

预览 `http://127.0.0.1:4186/solid-geometry/`。生成的 `site/solid-geometry/index.html` 与工作区根目录 `当当老师-立体图形观察站（离线版）.html` 均为不依赖网络的独立 HTML。

测试复用几何画板已安装的 Playwright：

```sh
node apps/solid-geometry/browser.test.cjs
node apps/solid-geometry/cabin.test.cjs
```

测试真实网页的几何数据，检查平面性、面积保持、铰链连接、无重叠、11 种正方体展开图、曲面展开、输入与体积、PNG、触控及小屋入口。

## 几何方法

各面通过面邻接树连接。每次渲染从原始顶点计算沿铰链的 Rodrigues 旋转，不积累上一帧误差。展开时面是刚体，每个父子面的共享边保持重合。正方体遍历面的生成树，过滤重叠并按平移、旋转和镜像归一，得到全部 11 种展开图。

圆柱、圆锥提供准确的平面展开预览，不把曲面伪装成可沿直棱展开的多面体。尺寸使用抽象长度单位。
