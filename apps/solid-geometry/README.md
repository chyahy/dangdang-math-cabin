# 当当老师 · 立体图形观察站

在用户提供的 `solid-geometry.html` 基础上扩展，原文件保持原样。

## 新增功能

- 棱柱、棱锥均可选择 3—12 棱，提供常用边数快捷按钮；各面的真实几何、顶点/棱/面计数、表面积及体积随选择同步改变。棱柱采用连接成一条侧面带的展开方式，避免底面边数多时各面重叠。
- 多面体沿公共棱连续展开与收回，可用滑块停在中间状态。
- 正方体 11 种不同展开图，附可点击缩略图；镜像和旋转重复形状不重复列出。
- 正方体、长方体都可按 1-4-1 型（6 种）、2-3-1 型（3 种）、2-2-2 型（1 种）、3-3 型（1 种）筛选展开方式。长方体各面按实际尺寸展开，缩略图与主画布采用相同的几何数据。
- 可逐一显示、隐藏各面，或只看棱线；长方体和正方体使用前后左右上下面名称。立体和展开状态共用选择，隐藏面不改变真实表面积。
- 正方体、长方体可独立勾选长、宽、高标注。数值取自真实棱长，随尺寸输入更新；与视线垂直的方向使用说明标签。
- 点击顶点高亮与其相连的棱；点击长、宽、高方向的任意一条棱，同方向 4 条棱同时高亮，正方体也按方向分组。其他多面体显示实际相连棱数或平行棱。提供下拉框进行键盘操作，支持手机点选。
- 圆柱：0—100% 连续改变侧面的曲率，最终成为长为 2πr、宽为 h 的长方形和 2 个圆形底面。
- 圆锥：0—100% 连续打开锥角，最终成为以母线为半径、扇形角为 360°×r/l 的扇形及 1 个圆形底面。
- 曲面展开可用鼠标或触屏拖动进度、点击自动展开或收拢，在中间进度停止后继续旋转、缩放和平移观察。底面保持刚性，通过保留的切点翻开。
- 球的无变形完整展开不可能，页面明确说明，保留其立体观察功能。
- 尺寸滑块和数字输入同步，体积、表面积与展开图实时更新。
- 当前画面导出 PNG，完整显示、全屏、手机双指缩放和平移。
- 小屋门边独立几何展台、展开入场动画、侧边快捷列表、第一人称 E 交互和返回小屋。
- 小屋射线交互按实际距离选择物品，避免后方门窗抢占眼前展台的操作。

## 构建、预览和测试

在仓库目录运行：

```sh
node apps/solid-geometry/build.mjs
node apps/solid-geometry/serve.cjs
```

预览 `http://127.0.0.1:4186/solid-geometry/`。生成的 `site/solid-geometry/index.html` 与工作区根目录 `当当老师-立体图形观察站（离线版）.html` 均为不依赖网络的独立 HTML。

测试复用几何画板已安装的 Playwright：

```sh
node apps/solid-geometry/browser.test.cjs
node apps/solid-geometry/curved.test.cjs
node apps/solid-geometry/cabin.test.cjs
```

测试真实网页的几何数据，检查平面性、面积保持、铰链连接、无重叠、11 种正方体展开图及 33 个不同尺寸的长方体展开结果、四类数量和缩略图行数、曲面展开、逐面隐藏、长宽高数值、真实顶点/棱点选、缩放后点选、拖动与点选区分、PNG、触控及小屋入口。

## 几何方法

各面通过面邻接树连接。每次渲染从原始顶点计算沿铰链的 Rodrigues 旋转，不积累上一帧误差。展开时面是刚体，每个父子面的共享边保持重合。正方体遍历面的生成树，过滤重叠并按平移、旋转和镜像归一，得到全部 11 种展开图。

圆柱使用弧长坐标和逐渐减小的曲率；圆锥保持母线距离和展开扇形角坐标，满足度量 `du² + u²dβ²`。两者均为连续等距展开，不在初始网格与最终网格间直接线性插值。54 个不同尺寸与进度的曲面状态检查局部长度、连接、底面刚性、切点接触以及完整展开的尺寸和面积。浏览器检查 3—12 棱的 20 个棱柱/棱锥、曲面 25/50/75/100% 状态、鼠标拖动与手机触屏进度控制。尺寸使用抽象长度单位。
