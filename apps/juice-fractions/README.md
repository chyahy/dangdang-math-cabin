# 乐乐喝果汁 · 当当老师小课堂

基于用户提供的《乐乐喝果汁_八等分连续互动版.html》修改。原文件留存于 `source-original.html`，保留连续喝水主题、BigInt 分数基础和三栏操作结构，重做双杯分量图和教学操作。

## 本地运行与发布构建

这是无需安装依赖的单文件 HTML，直接打开 `index.html` 即可离线使用。

仓库根目录运行：

```sh
node --test apps/juice-fractions/model.test.mjs
node apps/juice-fractions/build.mjs
node apps/portal/build.mjs
python -m http.server 8080 --directory site
```

打开 `http://localhost:8080/juice-fractions/`。门户构建最后运行，以安装返回游戏馆链接。

## 使用

- 主杯左侧从上到下为1/8至8/8，选择本次喝掉多少；右侧从上到下为8/8至1/8，选择本次剩下多少。两侧共用一个精确喝水量，始终满足“喝掉 + 剩下 = 操作前真实总量”。
- 两侧都支持点击、指针/触摸拖动及键盘方向键。Home和End选择该尺最上方/最下方的有效选项（包括0边界）。右侧滑块与虚线液面使用同一真实整杯比例尺，左侧则由上向下表示喝掉量。灰色刻度不可用；额外按钮支持“喝光当前液体”和“全部保留”。选择0不喝时禁用喝水按钮。
- 主刻度不随分母变化。对于非八等分的实际剩余量，额外保留精确的“喝光/保留全部”选项，滑块与旁边标签保留真实分数，不把体积舍入为八等分。
- 虚线以上为将喝掉的区域。喝水后，该区域移动到右杯；两杯容量和比例尺一致。黄色始终是果汁，紫色始终是水。
- 加水只增加水，直到满杯。不加水也可连续喝；没有果汁后可继续进行纯水实验。
- 分步演示按“圈出区域、分到右杯、分别收集并显示分量、看算式”依次推进；一键完成与取消都可用。累计收集在第3步完成时提交，同一口只记录一次。
- 下方黄色、紫色收集杯分别累计果汁和水，各杯最多1整杯。初始各有1个空杯，满整数杯不额外生成空杯。总量同时支持带分数与假分数。加水只改变主杯，不直接改变收集量。
- 收集杯超过6个时，较早的满杯可折叠展开；展开区域每次增量显示20杯，保持所有杯的真实序号与准确总量，逻辑上不限制杯数，也不一次分配巨大的DOM数组。
- 隐藏答案同时遮住杯内分数、分量卡片、累计分量、历史分量和算式，保留所选总量与滑条刻度。
- 撤销/重做恢复数据、选择量、答案开关和教学模式；重置也可撤销。重播只演示最新一次喝水，不增加次数或改变历史。

## 数学与显示

内联 `juice-model` 脚本以不可变 BigInt 有理数保存全部数学数据，不把长分数转成近似小数。只有绘图使用定精度数值。

液体高度 = 果汁 + 水；颜色宽度 = 各自数量 ÷ 当前总量。因此颜色面积始终对应实际数量。动画同样从分量计算几何，不独立插值高度和宽度。低于像素精度的极小分量不会被人为放大，其精确分数仍显示在杯下卡片中。

`juice-ui` 包含双侧滑条、四阶段控制器、撤销栈、累计收集动画和响应式渲染。动画进度只用于从操作前后状态插值显示；收集量不维护独立业务计数器。撤销/重做同时恢复收集杯数量、两侧联动值、精确分量和展开状态。没有真实流体模拟；左右分色只用于数学分量说明。

自动测试覆盖29项场景，包括全部双尺八等分互算、非八等分边界、两种液体的守恒、收集杯整数和超额分配、极大杯数、跨杯撤销重做及精确分数。

实际界面验证：两侧滑块鼠标拖动与点击互算；0不喝的禁用/恢复；两轮半杯后的3/4果汁和1/4水；水累计5/4、9/4时续第2、3杯及撤销重做；29/4水的满杯折叠展开；收集后取消、重播不重复累计；隐藏/揭晓答案。1920×1080下主要操作卡片完整显示，右滑块中心与虚线液面精确对齐；390、320像素竖屏与844像素横屏未出现横向溢出，控制台未发现脚本错误。

不含后端、账号、云端历史保存或测评系统；刷新页面会从初始一整杯重新开始。
