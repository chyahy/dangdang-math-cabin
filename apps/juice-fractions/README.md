# 乐乐喝果汁 · 当当老师小课堂

基于用户提供的《乐乐喝果汁_八等分连续互动版.html》修改。原文件留存于 `source-original.html`，保留连续喝水主题、BigInt 分数基础和三栏操作结构，重做双杯分量图和教学操作。

## 本地运行与发布构建

这是无需安装依赖的单文件 HTML，直接打开 `index.html` 即可离线使用。

仓库根目录运行：

```sh
node --test apps/juice-fractions/model.test.mjs
node apps/juice-fractions/build.mjs
node apps/portal/build.mjs
python -m http.server 8080 --directory site
```

打开 `http://localhost:8080/juice-fractions/`。门户构建最后运行，以安装返回游戏馆链接。

## 使用

- 左杯旁滑条选择本次喝掉的整杯体积，吸附 1/8 至 8/8，自动限制在现有液体量以内。也可用方向键、Home 和 End 操作。
- 虚线以上为将喝掉的区域。喝水后，该区域移动到右杯；两杯容量和比例尺一致。黄色始终是果汁，紫色始终是水。
- 加水只增加水，直到满杯。不加水也可连续喝；没有果汁后可继续进行纯水实验。
- 分步演示按“圈出区域、分到右杯、求出分量、看算式”依次推进；一键完成与取消都可用。
- 隐藏答案同时遮住杯内分数、分量卡片、累计分量、历史分量和算式，保留所选总量与滑条刻度。
- 撤销/重做恢复数据、选择量、答案开关和教学模式；重置也可撤销。重播只演示最新一次喝水，不增加次数或改变历史。

## 数学与显示

内联 `juice-model` 脚本以不可变 BigInt 有理数保存全部数学数据，不把长分数转成近似小数。只有绘图使用定精度数值。

液体高度 = 果汁 + 水；颜色宽度 = 各自数量 ÷ 当前总量。因此颜色面积始终对应实际数量。动画同样从分量计算几何，不独立插值高度和宽度。低于像素精度的极小分量不会被人为放大，其精确分数仍显示在杯下卡片中。

`juice-ui` 包含滑条指针/触摸、四阶段控制器、撤销栈、动画和响应式渲染。没有真实流体模拟；左右分色只用于数学分量说明。

不含后端、账号、云端历史保存或测评系统；刷新页面会从初始一整杯重新开始。
