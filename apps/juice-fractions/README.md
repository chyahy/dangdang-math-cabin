# 乐乐喝果汁 · 鲁老师×当当老师

基于原单文件课件增量修改，原文件存档为 `source-original.html`。

## 当前布局与操作

- 左侧操作区：十二等分选择、喝水、加水、分步演示、隐藏答案、撤销、重做和重置。
- 中间主杯：当前剩余果汁与水。左右刻度共用一个精确喝水量，喝掉量加剩余量始终等于操作前实际总量。
- 右侧：累计总液体，以及分别累计的黄色果汁杯、紫色水杯。已移除最近一口的独立展示杯和下方重复的累计展示区。
- 每个累计杯最多1整杯，超过时自动续杯；0时保留空杯，整数时不增加多余空杯，较早的满杯可以折叠展开。
- 每组累计杯下面分别显示“累计果汁的计算”“累计水的计算”，逐次列出“之前累计 + 这一口该成分的量 = 新累计”。加水记录不加入累计喝掉量。
- 分步演示依次圈出、移出主杯、累计收集、查看算式；取消、撤销和重做同时恢复杯子与两组计算过程。重播不重复累计。
- 隐藏答案同时隐藏分量标签与对应计算过程。

## 数学与动画

内联 `juice-model` 使用 BigInt 有理数精确运算。主杯液体高度等于总体积，两种颜色的宽度按各自占当前液体总量的比例计算。累计杯从同一状态派生，不独立维护业务计数器。

左右分色只是数学示意，没有真实混合、波浪或斜条纹。极小分量不人为放大，精确分数保留在标签中。

## 运行与验证

无需安装依赖，直接打开 `index.html` 可离线使用。仓库根目录运行：

```sh
node apps/juice-fractions/build.mjs
node apps/portal/build.mjs
node --test apps/juice-fractions/model.test.mjs apps/portal/portal.test.mjs
python -m http.server 8080 --directory site
```

门户构建最后运行以安装返回入口。访问 `http://localhost:8080/juice-fractions/`。

自动测试包含精确分数、12个刻度、边界、守恒、累计续杯、两组独立算式及右侧累计布局。实际浏览器验证了半杯连续操作、分步动画、撤销重做和手机宽度。没有后端或云端历史保存，刷新后从初始满杯开始。
