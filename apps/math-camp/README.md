## 已实现

- 混合运算逐步选取运算符、输入结果、保留未计算部分，含额外“填写下一行完整算式”训练。
- 算式合成：来源数字点击选择、卡片点击/鼠标或触屏拖拽、替换飞行动画、主动选择括号、补改括号、撤销与重来。
- 综合算式拆分：由学生逐步计算，自动积累分步算式卡片。
- 每模块5关、关卡解锁、课堂自由选关、引导/独立模式、原始数字范围10—500。
- 多结构随机生成，避开最近60道重复题，初级/当前所有题的中间结果均为非负整数，保证整除且不除以0。
- 方向性、具体、详细的逐级提示；独立模式的运算顺序在提交后检查。
- 每题1—3星；完成记录、用时、错误类型及当时算式、提示次数、错题原题重练/同级新题、真实条形报告。
- 当前题的树、操作历史、已填写内容和训练配置自动保存在本机 localStorage，可从大厅续练。
- 大按钮与键盘焦点、拖拽的点击替代、音效/动画开关、系统减少动画偏好。
- 小屋二楼新增可点击的算式积木板和合拢过场，第一人称交互与右侧游戏列表入口。

## 数学引擎设计

1. Pratt式递归优先级解析：只接受数字、加减乘除和配对括号，不运行学生输入，不使用 eval/Function。
2. 节点保留唯一ID。每轮从可计算节点中按括号层级、运算优先级、左右位置确定下一步。
3. 学生只提交当前运算的值，或额外填写下一行；判题与React界面完全分离。
4. 合成模块从树后序生成依赖卡片。数字同时保存 `ref` 来源节点ID，结果重复时也不会误用另一张卡片。
5. 合成检查先确保来源已展开，再解析学生实际选择括号后的文字算式，比较原始运算树和最终数值。冗余括号不影响判定；加法/乘法交换左右项允许，改变原分步依赖的重新结合不视为本题的正确合成。
6. 原题由合法算式树生成后重新解析，确保显示与判题完全一致。

## 本地运行与验证

需要 Node.js 22.12+（本次使用24）和 npm。从本目录执行：

```powershell
npm ci
npm run dev
```

开发地址由终端输出，默认 http://127.0.0.1:5173/ 。

```powershell
npm test
npm run build
npx playwright install chromium
npm run test:ui -- --workers=2
```

构建直接输出到 `../../site/math-camp/`。在仓库根目录部署 `site/` 就会同时发布小屋和此游戏。`test:ui` 自动启动4178端口的开发应用和4179端口的本地小屋静态预览。

## 第一版边界

- 不含注册、云端记录、教师账号、班级、支付或排名；不会收集孩子姓名等个人资料。
- 当前以整数四则运算为主，不提供分数、小数运算或负数专项题。
- 记录不跨浏览器/设备同步；清理浏览器站点数据会清除记录。用时是开始至完成的实际经过时间，包含离开页面的时间。
- 合成模块在识别错误来源时会即时提醒，以避免构造来源不明的积木；独立模式主要针对运算顺序与计算结果的延迟检查。
- 首次渲染的源码和生产构建均本地打包，不依赖远程字体、付费API、外部CDN。
- 手机为Chromium触屏仿真验证；尚未做真实iPhone Safari、安卓厂商浏览器的逐机验收。

## 后续教师端建议

先增加“教师创建练习单（题型/关卡/题量）→生成可分享的练习链接→学生用匿名编号完成”的流程，再考虑云端存档和班级汇总。后端接口独立接收本次已定义的 Question、Session 和 RecordItem 类型，保持数学引擎无UI依赖，便于服务端二次校验。儿童身份信息、班级访问控制和监护授权需在真正引入账号时单独设计。
