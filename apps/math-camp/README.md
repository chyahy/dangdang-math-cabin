## 已实现

- 混合运算逐步选取运算符、输入结果、保留未计算部分，含额外“填写下一行完整算式”训练。
- 算式合成统一采用：拖动来源积木到数字 → 无外层括号展开并整块高亮 → 两个大按钮“需要加括号 / 不需要括号” → 自动检查并继续。保留合法目标高亮、近距离吸附、点击来源再点击目标及键盘替代操作。
- 判断前隐藏等号与答案，只显示“待确认”。遗漏必要括号时保留展开状态重新选择；可省略的括号加了也算正确，只提醒简洁，不计错误、不扣星。所有积木判断完成后自动通关，不再需要额外的检查按钮。
- 混合运算返回完整的合法下一步集合，允许不同分支、不同括号深度的独立括号任选先算；括号外运算仍必须等待，未分组的同级运算仍从左到右。
- 小括号与中括号由同一AST排版函数生成，计算后动态重排；生成题默认不超过两层。提示时会高亮全部合法区域。
- 计算和合成都支持撤销/重做，算式与步骤记录一起恢复。已完成题重新操作时按题目ID更新同一记录，不重复发星星。
- 综合算式拆分：由学生逐步计算，自动积累分步算式卡片。
- 每模块5关、关卡解锁、课堂自由选关、引导/独立模式、原始数字范围10—500。
- 多结构随机生成，避开最近60道重复题，初级/当前所有题的中间结果均为非负整数，保证整除且不除以0。
- 合成模块额外要求每张卡片结果互不相同、每步结果为正整数且不超过原始数字上限的12倍；排除乘0/乘1、除1、加0/减0、相同数相减等无效步骤。其他模块仍可正常练习0和1。每关均有必须括号与可省略括号题，多步题可交替判断。
- 方向性、具体、详细的逐级提示；独立模式的运算顺序在提交后检查。
- 每题1—3星；完成记录、用时、错误类型及当时算式、提示次数、错题原题重练/同级新题、真实条形报告。
- 当前题的树、操作历史、已填写内容和训练配置自动保存在本机 localStorage，可从大厅续练。
- 待确认的括号状态也持久保存；刷新、撤销、重做都不会把未判断的预览当成正确等式。旧版本进度原地迁移，保留原记录和星星。
- 学习报告分别显示真实来源替换成功/失败、括号判断成功/遗漏、可省略括号提醒次数，不从旧记录推算操作数据。
- 大按钮与键盘焦点、拖拽的点击替代、音效/动画开关、系统减少动画偏好。
- 小屋二楼新增可点击的算式积木板和合拢过场，第一人称交互与右侧游戏列表入口。

## 数学引擎设计

1. Pratt式递归优先级解析：只接受数字、加减乘除和配对括号，不运行学生输入，不使用 eval/Function。
2. 节点保留唯一ID。先找“没有更内层待算括号”的独立分组，每个分组按AST依赖、乘除优先及同级左到右找一个可执行步骤。合并所有独立分组的步骤为合法集合，而不是按全局最深层排序。没有待算括号时才按普通运算链选步骤。
3. 学生只提交当前运算的值，或额外填写下一行；判题与React界面完全分离。
4. 合成模块从树后序生成依赖卡片。数字同时保存 `ref` 来源节点ID，不能只凭数值替换；即使旧存档中有重复值仍能拒绝错误来源。生成器展示前调用独立合法性校验器；校验器也支持包含多余卡片的外部分步列表。
5. `bracketDecision`只依据插入节点、父运算优先级、左右位置及分步依赖判断，不以最终数值碰巧相等为依据。同级运算的右侧子树也保留括号，避免重新结合改变给定的分步关系。学生决定是否加括号，系统仅自动选择圆/方括号样式。最终确认所有来源已展开、解析实际写出的文字式并比较运算树和数值。冗余括号不影响正确性。
6. 原题由合法算式树生成后重新解析，确保显示与判题完全一致。

## 本地运行与验证

需要 Node.js 22.12+（本次使用24）和 npm。从本目录执行：

```powershell
npm ci
npm run dev
```

开发地址由终端输出，默认 http://127.0.0.1:5173/ 。

```powershell
npm test
npm run build
npx playwright install chromium
npm run test:ui -- --workers=2
```

构建直接输出到 `../../site/math-camp/`。在仓库根目录部署 `site/` 就会同时发布小屋和此游戏。`test:ui` 自动启动4178端口的开发应用和4179端口的本地小屋静态预览。

## 第一版边界

- 不含注册、云端记录、教师账号、班级、支付或排名；不会收集孩子姓名等个人资料。
- 当前以整数四则运算为主，不提供分数、小数运算或负数专项题。
- 记录不跨浏览器/设备同步；清理浏览器站点数据会清除记录。用时是开始至完成的实际经过时间，包含离开页面的时间。
- 合成模块在识别错误来源时会即时提醒，以避免构造来源不明的积木；独立模式主要针对运算顺序与计算结果的延迟检查。
- 首次渲染的源码和生产构建均本地打包，不依赖远程字体、付费API、外部CDN。
- 手机为Chromium触屏仿真验证；尚未做真实iPhone Safari、安卓厂商浏览器的逐机验收。
