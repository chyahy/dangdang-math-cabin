# 单词王国：英语词汇攻防战

当当老师的双人英语金币策略游戏。与数学王国使用一致的五兵种、冰冻、箭塔、三级城堡、购买与胜负规则；保留英语单词题库及拼词/英译汉/缺字补全判题。React + TypeScript + Vite + Phaser + Zustand；无需后端或账号。

## 启动与构建

需要 Node.js 22.12+。在本目录运行：

```powershell
npm install
npm run dev
npm test
npm run build
node scripts/serve.cjs --open
```

生产预览默认 http://127.0.0.1:8917/ 。运行时无外部字体、CDN或付费API依赖。

部署到小屋：本目录 `npm run build:site`，再从仓库根目录运行 `node apps/portal/build.mjs`。独立入口 `/word-kingdom/`；原小屋与游戏广场入口保留。

## 英语课堂操作

1. 教师选择年级、单元、词库、难度、比赛时长、题型权重和策略/自动出兵模式。
2. 拼词依次点击字母块，再确认；允许退一步、清空。英译汉和缺字题选1个选项后确认，可改选。重复字母的卡片拥有独立ID，支持真实重复字母。
3. 答对简单/标准/挑战题分别获得15/20/30金币，每3连击额外5；答错或跳过中断连击。金币由本队使用，答对不直接赠送士兵。
4. 自行购买兵种或按教师配置的顺序自动储蓄购买。每队最多30个存活单位，达到上限不扣款；自动模式禁用手动出兵，仍可手动升级城堡。
5. 教师可全屏、暂停、调音量、重开、退出。失焦和隐藏页面自动暂停，需主动继续；暂停冻结时间、弹道、减速和战斗。
6. 双方使用相同单词顺序和题型安排，选项独立洗牌，各队独立推进。每轮不重复，耗尽可循环并标记轮次，或停止出题、继续购买和战斗。

## 词库与保存

- 内置72个示例词，四年级、五年级、初一各24个，不绑定教材。内置和自定义分别显示，搜索/年级/单元筛选只作用于当前来源，每页30个；新增、导入后自动切换到自定义列表。
- 保留手动增删改、Excel/CSV导入预览、错误校验、模板与完整词库导出。表头为 `word,meaning,grade,unit,difficulty,segments,distractors,acceptedAnswers`，数组字段用 `|` 分隔。
- 支持大小写等价与自定义可接受拼写。拼词卡片不通过文字匹配判断重复ID；词义干扰项来自真实词库，词库太小时回退拼词，不编造释义。
- 仅使用本机浏览器IndexedDB与localStorage，不是教师云同步。英语使用 `dangdang-word-kingdom` / `word-kingdom:`，数学使用不同存储，两版不会覆盖对方题库、设置、战绩。
- 旧设备的自定义单词和60/180/300秒设置保留，新增策略选项自动补齐；支持新120/240秒选项。旧战绩新增字段按0金币、Lv.1兼容显示，不虚构旧记录。
- 最近50场记录真实答题、金币、购买、城堡等级及错词；错词可导出CSV。

## 像素素材与结构

`src/engine` 为唯一战斗状态；`src/questions` 为英语题型与词条校验；`src/components` 处理双队答题、金币兵营与教师界面；`src/scenes` 用Phaser显示同一个Match。十套红蓝角色图集及冰晶位于 `public/math-pixel`，原生像素锚点与数学版一致，独立存储副本不改动其他游戏。旧 `public/art` 素材保留供历史版本使用。

`npm run package` 可生成离线和源码ZIP；离线包解压后运行 `start.cmd`，预装一次Node即可，无需安装依赖或联网。ES模块不能直接双击 `dist/index.html`。本机网址与线上网址的浏览器数据独立。

自动检查和浏览器验收见 `QA.md`。支持手机横屏和独立PointerID；实际65/75寸教学屏多点触控与性能需现场验证，浏览器尺寸测试不能代替实体设备测试。


## 当当老师 · 雷电兵种（2026-11-10）

数学、英语两版均可在兵营花200金币招募当当老师，也可在自动购买顺序中选择。黑发、眼镜、运动外套、书本与雷电法杖使用同一套原创像素角色流程，红蓝阵营有独立配色；待机、行走、施法、受伤、阵亡、蓄力共26帧。当前共10套角色及10张头像。

参数：150生命、2护甲、70移动速度、400射程，每2.6秒施法一次，前摇0.2秒。主目标基础伤害36，向其125单位内最多2个最近敌兵连锁，连锁基础伤害23，均按护甲减伤。友军、已死亡单位不受伤，最多命中3人；无人阻挡时对城堡造成18伤害，不以城堡为跳跃点。

前摇中施法者或主目标阵亡会取消；同一时刻完成的雷击先收集后同时结算，避免先遍历队伍占优。暂停冻结前摇与特效，结束后不再造成伤害，新局清空未完成法术。战绩记录当当老师购买次数，旧战绩缺失该字段时显示0；各游戏题库和设置继续独立。五兵种与城堡升级共6个按钮，手机横屏已重新压缩布局。
