# 单词王国：英语词汇攻防战

当当老师的双人英语课堂游戏。React + TypeScript + Vite + Phaser 3 + Zustand + IndexedDB + SheetJS；无需后端或账户。运行时无外部字体、CDN、图片或网络API依赖。

## 启动

需要 Node.js 22.12+。在本目录运行：

```powershell
npm install
npm run dev
```

```powershell
npm test
npm run build
node scripts/serve.cjs --open
```

开发服务器默认5173。最后一条命令在 `http://127.0.0.1:8917/` 打开生产构建；保留命令窗口，结束时按Ctrl+C。`npm run preview` 也可预览。

部署到现有小屋站点：`npm run build:site`，然后在仓库根目录运行 `node apps/portal/build.mjs`。独立路径 `/word-kingdom/`，游戏广场的英语词汇分类和小屋侧栏保留入口。

## 离线版

运行 `npm run build` 后执行 `npm run package`，在 `release/` 得到源代码包和离线包。离线包解压后双击 `start.cmd`。教学电脑需预先安装Node.js；启动和游玩无需联网，也不执行npm安装。不能通过双击 `dist/index.html` 的 `file://` 方式运行ES模块。

词库和战绩绑定当前设备的浏览器及网址。在线域名、开发端口、离线端口的数据彼此独立，可通过CSV导出/导入转移词库。离线版的返回游戏广场按钮会打开在线网站；它不影响本地比赛。

## 操作

1. 教师先进入游戏设置，选择年级、单元、词库来源、难度、时长与题型权重。
2. 两名学生分别在左右答题。乱序拼词逐块点击，再确认；英译汉、缺字补全先选再确认。可退一步、清空或跳过。
3. 答对召唤剑盾兵；连续3题额外弓箭手，5题额外骑士，8题范围闪电。每个阈值在一次连击中仅触发1次，答错/跳过后重置。
4. 士兵自动搜索敌人、移动、近战或射箭、推进与攻城。城堡归0立即结算；超时比较生命值，相同则平局。
5. 教师暂停按钮可调音乐/音效、继续、重开、退出。失去焦点/隐藏页面自动暂停，需明确点继续恢复。退出未完成对局需要确认。
6. 结算显示答题总数、对/错/跳过、正确率、最高连击、城堡生命与错词，可导出CSV。正确率分母包含跳过；本机保存最近50局。

## 词库管理

- 内置72条示例，四年级、五年级、初一各24条。属于主题示例，未声称对齐某一版教材。
- 支持手动增删改、按年级/单元筛选、搜索、Excel/CSV导入、预览错误、导出词库、CSV模板下载。
- 表头：`word,meaning,grade,unit,difficulty,segments,distractors,acceptedAnswers`。三个数组字段用 `|` 分隔。
- 难度为1/2/3；英文最长20字符，可含撇号/连字符；手动拆分最多8块且必须拼回原词，单块最多8字符；未配置则自动拆分。
- 导入最大5MB、2000条，读取第一张工作表。导入预览明确区分有效条目和错误条目；只在确认后保存有效数据。
- 每队使用同一份洗牌后的单词顺序和题型安排，独立推进，选项按阵营独立洗牌。每轮不重复，词量不足时教师明确选择循环并显示轮次，或停止该队出题；不会生成空白题。
- 同主题词义优先用于英译汉干扰项。极小词库只有1个不同释义时降级为拼词，避免编造答案。

## 战斗与架构

`engine/game.ts` 是唯一的战斗与答题权威状态；Zustand持有同一个Match对象，Phaser按1/30秒固定步长推进，React只显示该对象的变化。不存在两份各自计算的血量或胜负。

三兵种参数集中于 `engine/config.ts`：

| 兵种 | 生命 | 单次伤害 | 间隔/秒 | 速度/世界单位每秒 | 射程 | 攻城伤害 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 剑盾兵 | 32 | 10 | 0.8 | 115 | 58 | 8 |
| 弓箭手 | 21 | 9 | 1.15 | 100 | 320 | 6 |
| 重甲骑士 | 85 | 20 | 1.05 | 95 | 74 | 15 |

近战先收集双方攻击再统一结算，避免先遍历红队造成优势。箭矢以720世界单位/秒飞行，到达目标才扣血；目标已死亡则回收。闪电对敌军中心左右500单位范围造成32伤害。双方各最多36个存活单位；到上限后召唤转化为同类单位补充生命，界面操作不会无响应。单位、浮字使用对象池；粒子和事件有明确回收上限。

## 原创资产与音频

- 原创像素战场背景：`public/art/landscape-pixel-v2.webp`，640×150、31色无损图片；游戏广场使用配套像素封面。生成工具与完整prompt见 `ART_ASSETS.md`。
- 六个角色、两座城堡与旗帜：`src/scenes/art.ts`，原创低分辨率逐帧像素素材，剑盾、弓箭、重甲长剑有独立轮廓与动作。
- 战场以640×150原生画布绘制并以最近邻方式放大。数学世界仍为1920×450，相机缩放为1/3，战斗距离和速度不随美术改版改变。界面采用硬边木牌和像素奖杯，中文与题目保留清晰文字。
- 旧背景和 `src/scenes/art-vector-v1.ts` 保留供回退，不参与当前战场渲染。
- 实时音源：`src/scenes/audio.ts`，Web Audio原创合成，点击后初始化，无网络请求。音乐、音效分别调音量。
- 独立资源样本：`public/audio/` 的12种WAV效果和15.36秒原创主题旋律；`scripts/synth-audio.py` 可重建。网页使用实时合成以减少加载，并不在首屏下载这些WAV。
- 原创奖杯：`src/components/Trophy.tsx`。没有复制商业游戏角色或音乐。

## 测试与限制

自动化测试和实际浏览器验收见 `QA.md`。模拟覆盖公平对抗、速度差、单方推进、重复提交、重复字母、连击、箭矢、暂停、重开、结算与真实Excel/CSV读取。

已实现双队独立Pointer Events及pointerId追踪，但**没有连接65/75寸真实教学屏做硬件双点测试**；鼠标/浏览器检查不等于多点硬件验证。发布前应现场检查屏幕固件、多触点驱动、误触、声音和实际性能。60FPS是性能目标，非对所有设备的保证。低性能设备可降低特效。

背景为单张画，不是完整分离的多层视差资源；白云与旗帜独立动态。美术为原创复古像素奇幻风格，没有复刻商业游戏素材。没有开发用户账号、云端、联机对战或语音判读。
