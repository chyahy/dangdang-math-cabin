## 切割坐标与重合依据

坐标采用 SVG 方向，x 向右、y 向下。含“长、短”时令 l=max(a,b)、s=min(a,b)，保留实际 a、b 颜色。以下顶点列表与 `apps/pythagoras/src/proofs/` 的构造对应。程序中的斜边数值用于绘图，课堂证明用全等、相似、面积或圆的性质建立等式。

**01、05、02 的公共构型。** 斜边端点 B=(0,0)、C=(c,0)，直角顶点 A=(m,−h)，垂足 D=(m,0)，n=c−m。对边 BA 的外接正方形向外偏移 w=(−h,−m)，记 E=B+w、F=A+w；另一方块的相应外顶点记 H、G。斜边正方形底角 BL=(0,c)、BR=(c,c)。

- **01** 左方块按基向量 u=(m,−h)、w=(−h,−m) 构造。先保持 u，用 w→w+(h/m)u 得到竖直边，再保持竖直边和水平距离 m，把 u 剪切到水平，最后平移到目标。右方块镜像构造，水平距离为 n。两次剪切均保持同一底和相应高度。得到 m·c+n·c=c²。
- **02** 上部补三角形 [A,F,H]，下部补 [BL,BR,M]，M=(c−m,c+h)。上部沿 EG 切成 [E,F,H,G] 与 [E,B,C,G]，直角顶点 A 落在 EG 上。下部沿 AM 切得 [A,B,BL,M] 与 [A,M,BR,C]。左片绕 B 转 −90°，右片绕 C 转 +90°，两者分别覆盖 [E,B,C,G]；另一上片是该四边形关于 EG 的镜像。界面把右片翻到镜像位置后向右移开供观察。去掉上下组合中各两个全等三角形，得到 a²+b²=c²。
- **05** 斜边方块沿 x=m 切成两矩形，再沿 B→(m,c) 和 C→(m,c) 切对角线。左半选 [B,BL,(m,c)]，保持 B–BL，使顶部 (m,c) 沿 x=m 滑到 A。绕 B 转 −90° 得 [B,C,E]。以 B–E 为底，C 沿与底平行的直线滑到 F，得到 [B,E,F]。宽 n 的矩形围绕 C 作相反方向动作。另一半用矩形及小方块的中心对称配对。两次顶点移动均保持底和垂直高度，旋转保持全等。两矩形分别等积于两小方块。

**03、04、07 的公共构型。** 原直角点 O=(0,0)，短边外端 A=(0,−s)，长边外端 B=(l,0)。斜边方块其余两角 U=(s,−s−l)、W=(l+s,−l)。大方块为 [0,l]×[0,l]，小方块为 [−s,0]×[−s,0]。

- **03** 三角形绕 O 转 −90° 并移至直角点 (s,−s)。小方块平移 (s,0)。大方块切线 E=(0,l−s) 到 H=(l,l)。下三角形 [E,H,(0,l)] 平移 (s,−2l)。上四边形 [O,B,H,E] 绕 O 转 −90°，再平移 (s,0)。终形的轮廓由斜边方块和一个全等辅助三角形组成，抵消辅助面积。
- **04** 小方块沿 A→(−s,0) 切成两片。大方块令 E=(0,s)、F=(l−s,s)、G=(l−s,l)、H=(l,l)，沿 BE、BF、BG、EF、FG 切出 [O,B,E]、[B,E,F]、[B,F,G]、[B,G,H] 和 [E,F,G,(0,l)]。终点列表为 [A,B,(l,−s)]、[A,(s,−s),(s,−2s)]、[A,(s,−2s),U]、[U,W,(s,−l)]，后两侧用中点 (A+W)/2 作半转对应片，中心方块左上角在 (s,−l)，边 l−s。每片的平移和旋转从源顶点到终点的等距配准计算，镜像片先沿局部轴作翻转。s=l 时三个面积归零，其余四片覆盖目标。结论是两正方形总面积等于斜边正方形。
- **07** 外接矩形范围 [−s,l+s]×[−s−l,l]，沿 A→B 的延长线剪开。上下两梯形关于 (l/2,−s/2) 中心对称。左侧辅助区包括斜线顶部的小三角形、原三角形、左下 s×l 矩形的两半、右端小梯形。右侧有逐一全等的对应区。消去它们之后，左侧只剩两个直角边正方形，右侧只剩斜边正方形。

**06、08、09、10、11、12 的切片与变换。**

- **06** 把斜边横置，过长边方块中心 K 作 x=K.x、y=K.y 两条切线。四片顶点由凸多边形与相应象限的交集给出。右下、左下、左上、右上四片的平移量依次为斜边方块左上、右上、右下、左下顶点减 K，小方块中心移至斜边方块中心。正交切线两侧的边段经平移逐一共边，中心缺口四边与短边方块对应。
- **08** 两方块区域为 [0,l]×[0,l]、[l,l+s]×[l−s,l]。设 U=(0,0)、V=(s,l)、W=(l+s,l−s)、Z=(l,−s)。沿 UV、VW 切出左角 [U,V,(0,l)] 和右角 [V,W,(l+s,l)]。左角绕 U 转 −90°，右角绕 W 转 +90°。两角各跨越颜色分界时按原方块边界再分片并做相同旋转。目标 [U,V,W,Z] 四边是相同三角形的斜边且相邻边垂直。
- **09** 与 08 同样并底，但改用 U=(l,0)、V=(l+s,l)、W=(s,l+s)、Z=(0,s)。由 UV、UZ 及其平行延长边界切出中间区域、上角、右角和左下角。对应平移量为 (0,0)、(s,l)、(−l,s)、(l,−s)。左下角在等腰时消失。切片由相应半平面与原方块求交，顶点随边长更新。目标 [U,V,W,Z] 是相邻两边正交且等长的方块。
- **10** 令 k=1/√2，中线端点 T=(0,−2lk)、D=(0,2sk)，左部顶点 U=(−lk,−lk)、V=(−sk,sk)，右部顶点取水平镜像 Ur、Vr。分割线 TD。右片以 y=(T.y+D.y)/2 为水平轴翻面，移到右侧和左片副本合拢。新四边形 [U,flip(Vr),flip(Ur),V] 的四边是原三角形斜边，邻边垂直。顶端和底端空区与原两蝶翼全等，双方抵消。
- **11** 外框 [0,c]²，第一块顶点 (0,0),(c,0),(l²/c,ls/c)。另外三块依次绕 (c/2,c/2) 转 90°、180°、270°。四个内端点组成差方块，相邻三角形的长短直角边共线，空余长度为 l−s。出框后两两放入 l×s、s×l 矩形内，中心片移动到旁边。公式 c²=(b−a)²+2ab。
- **12** 沿 a 分横竖两线，将右上与左下的 a×b 矩形各沿对角线分成两片。目标按四角循环放置每片，令斜边围着中央空白。复用原站的刚体路径从第一排列反向播放到第二排列。两图都减去 4·ab/2，留下 a²+b² 或 c²。

**13–15 拓展。**

- **13** 先在原图两份副本中分别用 a、b 作统一倍率，使直角边变为 (a²,ab) 与 (ab,b²)。铺在共有 ab 边的两侧，利用互余锐角判断 a²、b² 两段共线；外侧 ac、bc 以两锐角互余得到直角。用两条直角边及夹角判与 c 倍图全等，所以 a²+b²=c²。
- **14** 在斜边水平的三角形上标出 α、β，满足 sinα=a/c、sinβ=b/c。等比放大 c 倍后，按顶点高度 h·c 建立矩形，两侧竖线给出顶部投影。投影各为 ac·sinα、bc·sinβ。正弦定义只用同角相似的边长比，不引用勾股定理或三角恒等式。矩形对边相等，a²+b²=c²。
- **15** 取 O=(0,0)、T=(0,b)、P=(a,b)，半径 b，单位方向 u=OP/c，近、远交点 N=b·u、F=−b·u。PT⊥OT 所以切线长度是 a，割线两段 PN=c−b、PF=c+b。用切线弦角与圆周角的关系，以及 P 处公共角，得 △PTN∽△PFT。它直接推出 PT²=PN·PF，无需勾股定理。平方差展开即得结论。
