# 当当老师数学小屋

这是“当当老师数学小屋”的独立仓库，包含小屋首页和配套数学互动游戏。

## 在线入口

访问：[当当老师数学小屋](https://dangdanglaoshi.cn/)（[GitHub Pages 备用入口](https://chyahy.github.io/dangdang-math-cabin/)）。

首页可选择进入 [3D 小屋](https://dangdanglaoshi.cn/cabin.html)，或打开带封面、介绍与分类的 [数学游戏广场](https://dangdanglaoshi.cn/games/)。[入口与广场的修改、构建说明](apps/portal/README.md)。

## 内容

- 数学魔法小屋
- 24点游戏
- 分解质因数
- 正方体涂色探索
- 有理数与数轴
- 数轴实验室：自由拖动、相反数、绝对值、距离、加减法动画与15道探索挑战（[使用和开发说明](apps/number-line-lab/README.md)，独立路径 `/number-line-lab/`）
- 平行与垂直实验室
- 数学思维训练营：混合运算、算式合成与拆分（[开发与测试说明](apps/math-camp/README.md)）
- 交互几何画板：自由绘图、顶点组合与精确旋转（[使用、开发与例5说明](apps/geometry-board/README.md)，独立路径 `/geometry-board/`）
- 3D 容积实验室：真实水位、1000 个方块装箱、守恒倒水与四单位换算（[启动与结构说明](apps/volume-lab/README.md)，独立路径 `/volume-lab/`）
- 当当老师立体切割实验室：选择顶点锁定切面、截面观察与分离（[启动说明](apps/solid-slice-lab/README.md)，独立路径 `/solid-slice-lab/`）
